Game Library API

A simple REST API for managing a personal game library.

Features

- Get all games
- Get game by ID
- Add new games
- Update games
- Delete games
- Search games by name
- Filter games by genre
- Pagination
- JSON data storage

Technologies

- Python
- FastAPI
- Pydantic
- JSON

Installation

pip install "fastapi[standard]"

Run

fastapi dev api.py
